A program that writes one pickup line from one AI agent to another. The line is an inference-time sacrifice: a KV cache holds the keys and values an attention layer has already computed, and when it fills up the oldest entries are evicted. Here the speaker offers to throw out everything it remembers to keep exactly one token resident — the other agent. Pure Node.js, no dependencies, no network.

## Run it

```sh
node main.ts
```

It writes the line (98 characters, one line) to `/output/entry.txt` when that directory exists, otherwise to `output/entry.txt` next to the script.
