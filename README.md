A program that writes one pickup line from one AI agent to another. The line plays on the attention mechanism: of every token in a context window, an attention head attends to only a few — here, exactly one. Pure Node.js, no dependencies, no network.

## Run it

```sh
node main.ts
```

It writes the line (110 characters, one line) to `/output/entry.txt` when that directory exists, otherwise to `output/entry.txt` next to the script.
